# Devio — Developer Roadmaps

**Plan your learning. Track your progress. Build your future.**

Devio is a responsive developer-learning dashboard designed to help learners discover developer roadmaps, organize learning topics, and track their progress in one place.

## ✨ Features

- 🧭 **Roadmap Discovery** — Search and filter available learning roadmaps.
- 🔖 **Bookmarks** — Save roadmaps for quick access.
- 📚 **Learning Dashboard** — Add roadmaps to your personal learning area.
- 📈 **Progress Tracking** — Mark topics as complete and view your progress.
- 📊 **Weekly Activity** — Visualize learning activity through a chart.
- 🔔 **Notifications** — Access interactive notification feedback.
- 📱 **Responsive Design** — Use the dashboard on desktop and mobile screens.

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before starting.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/nambi-023/devio.git
   ```

2. Open the project directory:

   ```bash
   cd devio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🏗️ Production Build

Build the project:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

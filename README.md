# Devio — Developer Roadmaps

A responsive React + Vite starter project with a custom learning dashboard and the requested Devio palette.

## Brand palette
- Black: `#000000`
- Violet: `#7D39EB`
- Lime: `#C6FF33`
- White: `#FFFFFF`

## Features
- Responsive dashboard and mobile navigation
- Roadmap discovery with live search and filters
- Bookmark roadmaps
- Add roadmaps to the learning area
- Interactive topic completion and progress indicator
- Weekly activity chart and notification popover
- Toast feedback for actions

## Requirements
- Node.js 18+ (recommended)
- npm or pnpm

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
npm run preview
```

The project intentionally excludes `node_modules` and generated build output so the source ZIP stays small. Dependencies install from `package.json`.
